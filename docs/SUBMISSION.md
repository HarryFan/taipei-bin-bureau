## 2. YouTube 影片腳本（約 2 分 30 秒）

**錄製方式**：電腦畫面用 Windows 的 Xbox Game Bar（`Win + G`）或 OBS；手機畫面用手機內建螢幕錄影。旁白可以後製配音，字幕建議加上（評審與票選者常靜音看）。

| 時間 | 畫面 | 旁白 |
| --- | --- | --- |
| 0:00–0:15 | 簡報封面：2,004 處 → 806 組 | 「2018 年台北有 2,004 處行人垃圾桶，今年 6 月只剩 806 組，約剩四成。」 |
| 0:15–0:35 | 簡報：會勘須里長同意 | 「垃圾桶增減要經過現場會勘，而且要里長同意。最需要垃圾桶的是路過的行人，但會勘時沒有人代表他們。」 |
| 0:35–1:05 | 手機：打開市民端，路牌指向最近的垃圾桶 | 「台北桶報局讓你一打開就知道最近的垃圾桶在哪、走幾分鐘、現在滿不滿。快滿了，會直接推薦下一個。」 |
| 1:05–1:30 | 手機掃 QR 貼紙 → 開到那一桶 → 按「這桶滿了」→ 綠點 | 「垃圾桶上貼 QR Code，掃了就能回報，不用下載 App。回報什麼狀態都拿一樣的點數，照實回報就好。」 |
| 1:30–1:40 | 手機掃假貼紙 → 驗證失敗 | 「如果貼紙被換掉，頁面會直接警告，而且我們從不在掃碼頁要求登入。」 |
| 1:40–2:05 | 電腦：市府戰情，回報跳出、切到清運調度、垃圾車沿路線移動 | 「市民的回報三秒內出現在市府戰情室，清運路線依填滿程度重新排序。」 |
| 2:05–2:20 | 市府戰情：缺口熱區、候選新設點、各區排名 | 「用捷運人流、公車站和陳情資料，找出人多卻沒有垃圾桶的地方，作為新設的候選點。」 |
| 2:20–2:35 | 簡報：落地 | 「這些回報就是會勘時行人的聲音。上任 100 天，我們會選一區試辦 QR 貼紙，接上環保集點和台北通。」 |

**注意**：
- 影片裡出現的數字照 [`DATA_SOURCES.md`](DATA_SOURCES.md) 第 0 節，一律帶單位與年份。
- 畫面上若出現「模擬資料」標記，旁白提一句「目前展示的是模擬資料」。
- 不要出現任何人的真實個資，也不要出現「市長你給我聽好了」資料集的原文截圖（僅限本活動使用），引用時改寫成摘要。
