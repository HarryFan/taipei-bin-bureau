## 2. 鏟屎特工隊（也是做垃圾桶）

他們說前面已經有三組分享過垃圾桶主題，所以只講不一樣的地方。

- **想解決的兩個問題**：如果要把垃圾桶放回去，要放在哪裡；放回去之後要怎麼管理得更好。
- **服務兩群人**：用資料做決策的人，以及參與管理、回報狀況的市民。
- **熱力圖**：公車站牌＋捷運資料代表人多。另外用「**狗便袋箱**」（垃圾桶上掛撿便袋的地方）當指標：代表常有人遛狗，遛狗的人會在附近丟垃圾，所以加分。附近沒有垃圾桶、公車站牌多，也會加分。不同因素用不同小圖示標示。
- **資料分析**：垃圾桶多快會滿、每個地點離垃圾桶多遠。
- **LINE 官方帳號**：大家手機都有 LINE，不用另外下載 App。可以找最近的垃圾桶；覺得「太遠了」就一鍵回報，當作增設的依據。
- **NFC 貼紙**：手機靠近垃圾桶上的 NFC 貼紙，就能回報有多滿、有沒有異味。

### 和我們的比較

| | 鏟屎特工隊 | 台北桶報局 |
| --- | --- | --- |
| 需求熱區 | 公車站、捷運、狗便袋箱、附近無桶 | 捷運人流、公車站、陳情、商圈（目前模擬）＋缺口模型 |
| 找垃圾桶 | LINE 官方帳號 | 網頁，不用下載；LINE 內建瀏覽器也能開 |
| 太遠了 | 一鍵回報好遠 | ✅ 會後補上：最近的桶超過 300 公尺就提示「太遠了」，一鍵回報這裡需要垃圾桶 |
| 現場回報 | NFC 貼紙 | QR Code 貼紙（含防偽簽章）；✅ 會後補上：貼紙可同時嵌 NFC，寫入同一個網址 |
| 回報之後 | 未提到 | 回報進度像追外送、派車、拍照結案、處理成績單 |

**我們的差異化**：他們停在「回報進系統」，我們把回報之後的事做完了，包括受理去重、分區派車、返隊、拍照、市民看得到進度，以及公開成績單。Demo 和影片要把這段講清楚。

## 4. 會後改良（2026/10/23 晚上）

1. **太遠了，一鍵回報**：市民端最近的垃圾桶超過 300 公尺時，最上方提示「最近的垃圾桶在 N 公尺外，太遠了？」，一鍵回報這裡需要垃圾桶。
2. **公開處理成績單** `/#/status`：不用登入，看各區 7 天回報數、處理中、已清運、平均處理時間；平均 60 分鐘內完成的區有「時效勳章」；列出最近完成的案件、處理分鐘數與清運照片。市民端回報進度卡、戰情室頂部都有入口。
3. **戰情室全市總覽**：每區多一欄平均處理時間，有時效勳章的區會亮綠色。
4. **QR 貼紙**：文字改成「掃描或手機靠近（NFC）」，貼紙可嵌 NFC 晶片，寫入同一個網址。
5. **資料待辦（青）**：找「狗便袋箱」或寵物便便清潔箱的開放資料，若有就加進需求點（source 可用 `pet`）。
