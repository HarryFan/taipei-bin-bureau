## 一、政策目標與跨局處分工

本計畫以「市民回報、即時處理、資料公開、持續改善」為核心，透過 QR Code 回報機制，串聯臺北通、既有清潔管理系統及開放資料平台，建立行人專用清潔箱的智慧化管理模式。

藉由市民日常使用清潔箱的經驗，協助市府掌握垃圾滿溢、清運頻率不足、設置位置不合理等問題，並將回報數據納入清運調度、清潔箱增設及設置地點會勘的決策依據。

為確保計畫有效推動，建議由臺北市政府環保局擔任主責機關，並建立跨局處協作機制，明確界定各單位權責。

### （一）環保局：統籌計畫與清潔管理

1. 負責全市行人專用清潔箱的管理、資料盤點及維護。
2. 統一規劃清潔箱 QR Code 貼紙的設計、張貼、巡檢及更新。
3. 指揮清潔隊依據市民回報、滿溢紀錄及現場狀況，檢討並調整清運車次與時間。
4. 將市民回報數據納入清潔箱設置、增設、移設及改善的會勘程序。
5. 定期公布回報處理情形、清運改善成果及相關統計資料。

### （二）資訊局：建置數位服務與資料平台

1. 評估運用既有臺北通 App 身分驗證機制，降低市民使用門檻。
2. 負責回報系統、後端資料整合及相關系統的開發與維運。
3. 整合臺北市政府開放資料平台，建立清潔箱點位、清運紀錄及改善成果的公開機制。
4. 建置管理儀表板，提供市府掌握案件處理進度及試辦成效。

### （三）研考會及 1999：整合陳情案件

1. 整合既有 1999 陳情系統，避免同一事件重複受理及重複派工。
2. 建立 QR Code 回報與 1999 案件的比對、轉派及結案機制。
3. 定期彙整垃圾滿溢、清潔箱不足及設置需求等案件，提供環保局作為政策改善依據。

### （四）民政局、區公所及里辦公處：串聯地方需求

1. 協助蒐集里鄰居民、商家及地方組織對清潔箱設置與清運服務的意見。
2. 於相關會勘中提供市民回報彙整資料，確保實際使用需求納入評估。
3. 協助推廣回報機制，並建立地方意見與市府執行單位之間的溝通管道。

### （五）交通局及臺北捷運公司：補足交通場站需求資訊

1. 針對捷運站、公車站及周邊人潮密集區域，評估清潔箱設置需求。
2. 在符合法令、個資保護及資料使用規範的前提下，提供適當的人流或運量統計資料。
3. 結合市民回報、旅運需求及現場會勘結果，優化清潔箱設置位置與數量。

### （六）教育局：推動校園環境教育與學生參與

- 結合環境教育、資源回收及公民參與課程，宣導清潔箱正確使用方式與公共環境維護觀念。
- 鼓勵學校結合服務學習、社區參與及環境教育活動，辦理校園周邊清潔箱巡查或社區環境觀察，協助蒐集清潔箱設置、滿溢及周邊環境問題的回報資料。
- 鼓勵學校與區公所、里辦公處及地方組織合作，將通學步道、校園周邊人行道及學生經常通行路段的清潔需求，納入清潔箱設置與管理評估。
- 協助宣導 QR Code 市民回報機制，讓學生、教師及家長了解如何透過數位工具反映環境問題，培養公共事務參與及環境責任意識。
- 在符合學生安全、個人資料保護及教育相關規範的前提下，鼓勵學校參與試辦與成果回饋，協助市府掌握校園周邊的清潔需求。

## 二、開放資料與管理資訊補強

目前清潔箱相關資料仍有欄位不足、清運紀錄未公開及設置決策缺乏完整資訊等問題。建議以「資料完整、定義一致、定期更新、可供分析」為原則，逐步建立清潔箱管理資料庫。

### （一）補齊清潔箱點位資料

現有清潔箱點位開放資料集（121355）共計 661 筆點位資料，但缺乏「組數」等重要欄位。依目前初步推估，全市約有 806 組、1,612 座清潔箱，實際數量仍應由環保局盤點確認。

建議採取以下措施：

1. 逐筆核對現有 661 筆點位資料，補齊缺漏及錯誤資訊。
2. 新增「組數」及「座數」欄位，並建立固定的資料更新機制。
3. 明確定義「組、座、處、個」等統計單位，避免不同資料集採用不同計算口徑。
4. 視管理需求增加設置地址、座標、管理單位、設置狀態及最後更新日期等欄位。

### （二）公開清運及滿溢紀錄

建議由清潔隊提供去識別化的清運時間、清運頻率、滿溢回報及改善紀錄，讓市府與市民能夠掌握各區域的實際清潔需求。

透過長期資料分析，可找出容易滿溢的熱點，作為調整清運班次、改善清運時段及評估增設清潔箱的依據。

### （三）公開清潔箱設置會勘紀錄

建議建立標準化會勘資料欄位，公開會勘時間、地點、評估結果、決議理由及後續辦理情形。

針對未獲同意的增設或移設需求，應提供具體理由，提升決策透明度，並讓市民能夠追蹤意見是否獲得實質處理。

### （四）補充 1999 垃圾相關案件地點

現有垃圾相關陳情資料雖有案件類別，但缺乏足以分析區域需求的地點資訊。

建議在個人資料及案件隱私受到妥善保護的前提下，提供去識別化的區域資訊，以里別或適當網格呈現案件分布，協助辨識垃圾滿溢、清潔箱不足及清運服務需求較高的區域。

### （五）開放公車站上下車人次資料

建議交通局逐步開放各公車站上下車人次統計，並與捷運場站及其他可取得的人流資料交叉分析，補足清潔箱設置評估所需的需求資訊。

相關資料應以適當的統計尺度及格式提供，並建立固定更新週期，供市府、研究單位及民間團體進行分析與應用。

## 三、試辦計畫與經費規劃

### （一）西門町 100 天試辦計畫

- **試辦場域**：西門町商圈
- **試辦期間**：市長上任後 100 天
- **試辦規模**：50 至 100 個清潔箱點位
- **提案預算**：新臺幣 50 萬元
- **預計合作單位**：臺北市政府環保局、萬華區清潔隊、資訊局、萬華區公所、地方組織、西門町商圈組織及商家，以及學校、企業與公益團體。

本試辦計畫以低成本、快速驗證為原則，優先運用既有數位平台與清潔管理資源，不以全面建置新系統或大量安裝感測器為前提。

試辦期間主要工作如下：

1. 完成試辦區清潔箱盤點及點位資料校正。
2. 張貼專屬 QR Code 貼紙，建立市民回報入口。
3. 建置回報、派工、處理及結案的基本流程。
4. 由清潔隊依據回報紀錄檢討清運時段與頻率。
5. 將回報熱點納入清潔箱增設、移設及改善評估。
6. 公開試辦成果，評估後續擴大推動的可行性。

### （二）試辦區推廣及營運經費估算

**1. QR Code 耐候貼紙**

貼紙將作為市民回報的主要入口，應具備耐候、防水、易辨識及便於掃描等特性。

以萬華區推廣規模初步估算，若有 77 組清潔箱、每組 2 座，則為 154 座；若每座張貼 1 張貼紙，初始需求量為 154 張，另須預留備品及汰換數量。

貼紙單價及實際需求，應依清潔箱盤點結果、張貼位置與廠商報價確認。

**2. 市民回報獎勵**

建議評估與環保集點機制合作，對經系統確認且符合規則的有效回報提供綠點獎勵。

依 77 組、每週每組確認 2 次、每次獎勵 1 元的假設估算：77 組 × 每週 2 次 × 每次 1 元 × 52 週，全年約為 **8,008 元**。

上述金額為依照每週固定回報次數計算的示意值，尚未包含系統整合、活動推廣、資格審核及行政管理等成本。實際獎勵應依有效回報量及預算上限另行設計。

**3. 系統開發與維運**

優先沿用臺北通、既有陳情系統及開放資料平台，新增必要的 QR Code 回報、案件派工、狀態追蹤及管理儀表板功能。

由資訊局會同環保局盤點既有系統的整合能力，再提出開發成本、維運需求、資安措施及預估時程，避免重複建置。

**4. 智慧感測器（選配）**

不建議一開始即全面安裝智慧感測器。

應先挑選垃圾滿溢頻率高、清運需求不易掌握的點位進行小規模測試，並與市民回報、實際巡查及清運紀錄進行比較，再依準確度、維護成本與實際效益決定是否擴大。

**5. 經費控管原則**

新臺幣 50 萬元為本次提案的試辦預算上限規劃，應優先投入資料盤點、貼紙製作、既有系統整合、宣導及成效評估。各項單價與實際支出仍須經相關單位估價及預算審查後確認。

## 四、推廣策略與市民參與

本計畫以「清潔箱就是服務入口」為推廣理念，讓市民在日常生活中即可參與城市清潔管理，並透過透明的處理流程，建立市民回報與市府改善之間的正向循環。

1. **QR Code 隨掃隨報**：在清潔箱張貼 QR Code，讓市民能快速回報垃圾滿溢、清潔箱損壞、設置不足等問題，並提供清楚的處理進度查詢方式。
2. **串聯臺北通與環保集點**：評估透過臺北通推播及環保集點獎勵機制，鼓勵市民參與清潔環境維護。獎勵制度應以有效回報為原則，避免重複回報或不實回報，並兼顧公平性及行政成本。
3. **優先推廣交通場站及人潮密集區**：針對捷運站、公車站、商圈、觀光景點及人流密集路段，優先設置回報入口並加強宣導，提升回報機制的可見度及使用率。
4. **結合里辦公處與第一線清潔隊**：透過說明會及操作訓練，讓里長、里幹事、區公所及清潔隊了解回報資料如何影響清運調度與設置會勘，降低第一線人員的執行負擔，並爭取地方支持。
5. **結合學校、社區及公益組織**：舉辦「巡桶日」或社區環境觀察活動，鼓勵學生、志工及社區居民協助核對清潔箱位置、確認設置狀況及回報環境問題。若結合志願服務時數，應依相關規定辦理。
6. **建立公開戰情儀表板**：透過公開儀表板呈現回報案件數、處理進度、改善完成率、滿溢熱點及清潔箱增設成果，讓市民看見回報是否轉化為實際改善，建立可追蹤、可檢驗的政策回饋機制。

## 五、市長上任 100 天推動時程

### 第 1 至 30 天：盤點資料、建立制度

1. 由環保局完成清潔箱資料盤點，確認全市點位、組數及座數的統計口徑。
2. 補齊清潔箱點位資料，研議公開清運、滿溢及會勘紀錄。
3. 訂定市民回報資料納入清運調度及設置會勘的標準作業程序。
4. 由資訊局、研考會及環保局確認系統整合需求與權責分工。
5. 完成西門町試辦點位選定、合作單位協調及經費細項規劃。

**階段成果**：完成基礎資料盤點、制度草案及試辦執行方案。

### 第 31 至 60 天：啟動試辦、落實回報

1. 在西門町 50 至 100 個試辦點位張貼 QR Code 貼紙。
2. 啟用市民回報機制，建立案件受理、分派、處理及結案流程。
3. 由萬華區清潔隊依據回報資料，檢討清運車次、時間及熱點巡查安排。
4. 整合既有 1999 案件資訊，降低重複陳情與重複派工。
5. 建立試辦成效追蹤機制，定期彙整回報量、處理時間及改善情形。

**階段成果**：回報機制正式運作，清潔隊開始依據資料調整服務，並建立可供檢討的初步數據。

### 第 61 至 100 天：檢討成效、決定擴大方向

1. 分析回報量、案件處理時間、滿溢改善情形及重複陳情比例。
2. 檢視市民回報是否實際影響清運調度及清潔箱設置會勘結果。
3. 公布試辦成果及後續改善事項，說明未完成項目的原因與預定處理方式。
4. 評估與環保集點整合的技術、經費及執行可行性。
5. 依據成效、成本及第一線執行負擔，提出擴大至萬華區或其他行政區的推動方案。

**階段成果**：完成試辦成效報告，提出下一階段推廣範圍、經費需求及執行計畫。

## 六、績效指標與後續擴大原則

為避免計畫僅停留在貼紙張貼或系統建置，建議同步建立量化及質化績效指標。

1. **資料完整度**：清潔箱點位、組數、座數及管理資訊的盤點與補齊情形。
2. **市民參與度**：有效回報量、重複回報比例及參與人次。
3. **處理效率**：案件平均處理時間、結案率及逾期案件比例。
4. **清潔改善成效**：試辦點位滿溢頻率、清運調度改善情形及重複發生問題的變化。
5. **決策應用程度**：市民回報資料實際納入清潔箱增設、移設及會勘評估的案件數與比例。
6. **財務效益**：每件有效回報成本、系統維運成本及各項措施的實際改善效益。

各項指標應先建立試辦前基準值，再由環保局會同相關單位訂定合理目標，避免在缺乏基礎數據的情況下設定不切實際的績效數字。

## 七、結語：讓每一次回報，都成為城市改善的依據

清潔箱管理不應只依賴既有巡查與陳情機制，更應善用市民日常使用經驗、清運紀錄及公共運輸人流資料，建立更精準、更透明的城市清潔治理模式。

本計畫以西門町 100 天試辦為起點，優先整合既有平台、補齊公開資料、改善清運流程，並透過可追蹤的回報與處理機制，讓市民意見真正進入市府決策。

**政策的目標不只是讓市民能夠回報，而是讓每一次有效回報，都有機會轉化為清運改善、設置優化及公共環境品質的提升。**
